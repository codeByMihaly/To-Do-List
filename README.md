# To‑Do List Web Application

A modular, responsive To‑Do List application built with **vanilla JavaScript, HTML, and CSS**.  
The app supports multiple projects, task creation, editing, deletion, and status updates. All stored persistently using `localStorage`.

## Features

- **Multi‑project support**  
  Create, switch, and delete projects with real‑time sidebar updates.

- **Task management**  
  Add, edit, delete, and mark tasks as done.

- **Dynamic UI rendering**  
  The interface updates instantly without page reloads.

- **Modular architecture**  
  Clear separation of concerns: rendering, data handling, UI logic, and form control.

- **Persistent storage**  
  All projects and tasks are saved in `localStorage`.

- **Responsive layout**  
  Built with CSS Grid and flexible components for a clean, consistent UI.

## Tech Stack

- **JavaScript (ES6 modules)**
- **HTML5**
- **CSS3 (Grid, Flexbox)**
